# Roubenka Ořechovka

Prezentační web pro Roubenku Ořechovka zaměřený na představení ubytování, okolní přírody a praktických informací pro návštěvníky.

Web bude dostupný na doméně [roubenkaorechovka.cz](https://roubenkaorechovka.cz).

## Cíl projektu

Cílem je vytvořit přehledný a vizuálně příjemný web, který návštěvníkům představí roubenku, její vybavení a okolí. Web nebude obsahovat vlastní rezervační systém. Rezervace budou řešeny prostřednictvím odkazu na externí službu Booking.com.

Obsah a vizuální styl webu budou stavět především na přírodě, klidném prostředí a autentické atmosféře roubenky.

## Stránky

Web bude tvořen čtyřmi hlavními stránkami:

1. **Úvodní stránka** – hlavní fotografie roubenky se stromem, krátké představení ubytování, sekce O nás a odkazy na důležitý obsah.
2. **Ceník** – přehled cen a základních podmínek pobytu.
3. **Galerie** – fotografie interiéru, exteriéru a okolní přírody.
4. **Kontakt** – kontaktní údaje, mapa, sociální sítě a odkaz na rezervaci.

## Hlavní funkce a obsah

- responzivní zobrazení pro počítače, tablety i telefony,
- navigační lišta na desktopu a hamburger menu na mobilních zařízeních,
- výrazný odkaz na rezervaci přes Booking.com,
- odkazy na sociální sítě,
- mapa s polohou roubenky,
- odkazy na aktuální počasí, webkameru a tipy na výlety,
- prezentace roubenky, jejího vybavení a okolní přírody,
- základní SEO včetně vhodných titulků, popisů stránek, nadpisové struktury a alternativních textů obrázků.

## Vizuální směr

Web bude působit přírodně, klidně a útulně. Úvodní část bude založena na výrazné fotografii chalupy se stromem. Barevnost a typografie budou vycházet z materiálů a atmosféry roubenky, aby vizuální zpracování podporovalo její charakter a nenarušovalo přehlednost obsahu.
